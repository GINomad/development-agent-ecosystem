A running workflow reads new comments at its next handoff checkpoint. For a stopped task, save the comment and select Resume workflow.

Windows policy blocked the Codex sandbox for this task. Use the normal resume only after the policy is fixed, or use the elevated workflow action for one explicitly confirmed task session.
Send comment
Saves your instruction in the task ledger. A running workflow reads it at the next handoff; it does not start or resume a stopped task.
Resume workflow
Continues the same task and history in the normal Codex sandbox. This is the default and safest resume action.
Resume workflow elevated
Continues the complete task without the Codex OS sandbox after a confirmation. Use for policy error 1260; requirement, review, credential, and external-write gates still apply.
Approve elevated repair
Allows Health Check one elevated attempt to repair the ecosystem itself. It does not resume product implementation or authorize product-code changes.
