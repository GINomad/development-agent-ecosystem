Send comment
Queues an instruction for the active agent's next end-of-block checkpoint, or resolves the selected Reply target. A running agent continues without restart; a stopped task stays stopped.

                
Resume workflow
Continues from the persisted checkpoint and starts only unfinished agents. Completed agents and artifacts are preserved.

                
Stop workflow
Stops this task's active process tree or runspace, preserves history and completed work, and marks running agents as waiting.

                
Resume workflow elevated
Continues only unfinished agents in an in-process host runspace without a nested PowerShell or Codex OS sandbox. Use for policy error 1260; all delivery gates still apply.

                
Approve elevated repair
Allows one elevated ecosystem repair. After validation, Health Check restarts only the failed agent once; it does not restart other agents, authorize product-code changes, or bypass review and external-write gates.
